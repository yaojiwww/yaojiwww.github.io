微控制器简介

发布于：2026-07-08 所属专栏：STM32

什么是嵌入式系统

在你阅读这篇文章的时候，你身边大概率已经被几十个嵌入式系统包围了——你的智能手表在计步、空调在根据温度自动调节风速、汽车的防抱死制动系统（ABS）在默默保护你的安全。它们都不是”电脑”，但它们内部都藏着一个小型的计算单元，在不知疲倦地运行着程序。

嵌入式系统（Embedded System） 是一种以应用为中心、以计算机技术为基础，软硬件可裁剪的专用计算机系统。它被”嵌入”到更大的设备中，专注于完成特定的任务，实时性很强。

让我们看几个生活中真实的例子：

  • 智能家居：你对着天猫精灵说”打开客厅的灯”，音箱里的嵌入式芯片负责语音识别、Wi-Fi 通信、控制指令的发送。这个芯片不需要运行 Windows，不需要 16GB 内存，它只需要做好”听懂你说话并控制灯”这一件事。

  • 汽车 ECU：一辆现代汽车里有 70~100 个 ECU（电子控制单元）。发动机管理、变速箱控制、安全气囊触发、车窗升降……每一个功能背后都有一个独立的嵌入式系统在工作。

  • 无人机：大疆无人机的飞控系统是一个典型的嵌入式实时系统。它需要在毫秒级的时间内读取陀螺仪数据、计算姿态、调整四个电机的转速，任何延迟都可能导致炸机。

看到了吗？嵌入式开发的本质，就是为这些设备里的计算单元编写程序。 你写的代码不会运行在一台有显示器、键盘的电脑上，而是运行在一块小小的芯片里，控制着真实世界中的硬件。

这和写网页、写 App 的体验完全不同——你面对的不再是像素和按钮，而是电压、时序、寄存器和中断。

微控制器（MCU）是什么

嵌入式系统的核心硬件就是微控制器，英文全称叫 MCU（MicroController Unit）。

你可以把 MCU 理解成一台超级迷你的电脑，它把 CPU、内存（RAM）、存储（Flash）、各种外设接口全部集成在一颗芯片上。这种”片上系统”的设计让它体积小、功耗低、成本低，非常适合嵌入到各种设备中。

MCU = CPU + RAM + Flash + 外设（GPIO、UART、SPI、I2C、ADC、定时器……），全部集成在一颗芯片内。

下面用一张表格来对比 MCU、CPU 和 MPU 的区别：

特性 MCU（微控制器） CPU（中央处理器） MPU（微处理器）
代表产品 STM32、ESP32、Arduino Intel i7、AMD Ryzen ARM Cortex-A 系列（树莓派）
集成度 极高（CPU+RAM+Flash+外设） 极低（只有运算核心） 中等（CPU+MMU，需外接 RAM）
主频 几十 MHz ~ 几百 MHz 几 GHz 几百 MHz ~ 几 GHz
内存 几十 KB ~ 几 MB（片上） 需要外接 GB 级 DDR 需要外接几百 MB ~ GB 级
操作系统 裸机 / RTOS（FreeRTOS） Windows / macOS / Linux Linux / Android
单价 ¥2 ~ ¥50 ¥500 ~ ¥5000 ¥30 ~ ¥500
典型场景 传感器采集、电机控制、物联网节点 个人电脑、服务器 智能手机、平板、路由器

“微”不是指物理尺寸小。 MCU 之所以叫”微控制器”，不是因为芯片本身很小（虽然确实不大），而是因为它的输出驱动能力有限——GPIO 引脚通常只能输出 3.3V / 20mA 左右的电压和电流，无法直接驱动大功率设备（如电机），需要通过外部驱动电路来放大信号。

简单来说：MCU 是嵌入式系统的大脑，它小而全、省电便宜，专门干脏活累活。

认识 STM32

STM32 是目前全球最流行的 32 位微控制器系列之一，让我们拆解一下它的名字：

  • ST → 意法半导体（STMicroelectronics），总部位于瑞士日内瓦，是全球前十的半导体公司

  • M → Microcontroller，表明这是微控制器产品线

  • 32 → 32 位架构，表示 CPU 一次能处理 32 位（4 字节）的数据

STM32 系列全部基于 ARM Cortex-M 内核。ARM 公司自己不生产芯片，而是设计 CPU 内核架构并授权给其他厂商使用。ST 拿到 ARM Cortex-M 内核的授权后，围绕它添加了自己设计的外设（GPIO、UART、DMA、ADC 等），最终封装成 STM32 芯片。

类比一下：ARM 像是提供”发动机图纸”的公司，ST 则是造整辆车的厂商——发动机用 ARM 的设计，但底盘、变速箱、内饰都是 ST 自己搞的。

为什么推荐从 STM32 入门？ 有三个核心理由：

  1. 价格亲民：STM32F103 系列芯片单价约 ¥515，一块完整的开发板 ¥50150 就能拿到手，学习门槛极低。

  2. 中文资料极其丰富：野火、正点原子、硬石等国内厂商出了大量免费教程、视频和配套代码。遇到问题，中文搜索基本都能找到答案。

  3. 社区庞大活跃：从 CSDN、知乎到 B 站，STM32 的学习社区是所有 MCU 中最活跃的。你遇到的 90% 的坑，别人都已经踩过并分享了解决方案。

常见的 Cortex-M 内核系列：

内核 定位 STM32 对应系列 典型应用
Cortex-M0/M0+ 超低功耗入门 STM32F0、STM32L0、STM32G0 简单 IO 控制、低功耗传感器
Cortex-M3 主流性能 STM32F1、STM32F2、STM32L1 通用控制、工业应用
Cortex-M4 主流 + DSP/FPU STM32F3、STM32F4、STM32L4、STM32G4 电机控制、音频处理
Cortex-M7 高性能 STM32F7、STM32H7 图形界面、高速通信
Cortex-M33 安全 + 高效 STM32L5、STM32U5 物联网安全、可穿戴设备

STM32 产品命名规则

STM32 的型号看起来像一串乱码，但其实每一段都有明确含义。根据MCU的具体名称，可以解决我们大部分开发时面临的产品选型问题。以本教程使用的 STM32F103VET6 为例：

位置 字符 含义 可选值示例
第 1~5 位 STM32 产品系列标识 固定值，表示 ST 的 32 位 MCU
第 6 位 F 产品类型 F = 基础型（Foundation）、L = 低功耗（Low-power）、H = 高性能（High-performance）、G = 主流型（Mainstream）、W = 无线型（Wireless）
第 7~9 位 103 产品子系列 101 = 基本型、103 = 增强型、105/107 = 互联型、407 = 高性能+DSP+FPU
第 10 位 V 引脚数量 T = 36 脚、C = 48 脚、R = 64 脚、V = 100 脚、Z = 144 脚、B = 208 脚
第 11 位 E Flash 容量 8 = 64KB、B = 128KB、C = 256KB、E = 512KB、G = 1024KB
第 12 位 T 封装类型 H = BGA、T = LQFP、U = UFQFPN、Y = WLCSP
第 13 位 6 工作温度范围 6 = 工业级（-40°C ~ 85°C）、7 = 工业级（-40°C ~ 105°C）

所以 STM32F103VET6 翻译过来就是：

ST 的 32 位基础型增强系列微控制器，100 引脚，512KB Flash，LQFP 封装，工业级温度范围。

掌握了这个命名规则，你以后看到任何 STM32 型号都能快速判断它的大致规格。比如看到 STM32F407ZGT6，你立刻就知道：F4 系列（Cortex-M4 内核）、144 引脚、1MB Flash、LQFP 封装、工业温度。

开发板推荐

学习嵌入式，一定要买实体开发板。仿真器和模拟器永远无法替代你亲手用杜邦线接电路、用示波器看波形、用万用表测电压的体验。只有真正跟硬件打交道，你才能理解”为什么这个引脚要配置成推挽输出”、”为什么串口波特率对不上就是乱码”。

本系列教程基于 野火指南者开发板（STM32F103VET6），推荐理由：

  • 配套资料完善：野火提供了完整的原理图、PCB 图、数据手册、中文教程和配套源码，全部免费开源，作者学习和编写时也参考了野火的中文教程，受益良多

  • 外设丰富：板载 LCD 屏、蜂鸣器、LED、按键、USB 转串口、SD 卡槽、SPI Flash、温湿度传感器等，一块板就能学完大部分外设

  • 价格合理：淘宝约 ¥100~150，性价比极高

  • 社区支持：野火论坛活跃，遇到问题容易找到答案

如果你手边有其他 STM32F103 系列的开发板（如正点原子战舰、硬石 YS-F1Pro 等），也完全可以跟着学。核心芯片相同，只是板载外设布局不同，代码稍作修改即可适配。

当然，除了开发板本身，你还需要准备：

  • ST-Link V2 调试器（通常开发板会附赠，用于烧录程序和在线调试）

  • USB 数据线（Micro-USB 或 Type-C，取决于开发板型号）

  • 杜邦线若干（公对公、母对母、公对母各准备一些）
