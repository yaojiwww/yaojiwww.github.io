# 🚀 启航：我的个人技术博客上线了！

你好，世界！今天我的个人博客正式在 GitHub Pages 上线了。

之前一直在考虑是自己买服务器、解析域名、配置 Nginx 甚至自己手写后端，还是找一个现成的平台。最终我选择了 **GitHub Pages + Hexo** 的纯静态网站托管方案。

### 为什么选择自己搭博客？
1. **完全掌控的自由：** 本地项目在手，我可以 100% 自定义每一个 HTML 标签和 CSS 样式。比如后续我可以自己去魔改主题的 `layout` 结构。
2. **纯粹的写作体验：** 用 VS Code 写 Markdown，配合 macOS 终端一键发布，这种极客工作流非常丝滑。
3. **结构化知识沉淀：** 这里未来会成为我的“第二大脑”。我打算用它来记录以下内容的学习笔记和速查手册：
   - **Web 前端探索：** HTML 属性、页面结构及底层资源引入逻辑。
   - **硬核工程记录：** 硬件电子电路、微控制器、LDO 稳压芯片原理等。
   - **机器人与系统：** Ubuntu 环境下的 ROS 节点配置与嵌入式开发。
